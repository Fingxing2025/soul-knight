# 元气骑士 · 复刻版 (Soul Knight Clone)

一个基于 HTML5 Canvas 的俯视角地牢射击游戏，灵感来自《元气骑士》。纯前端实现，没有任何构建步骤和第三方依赖。

## 玩法简介

穿越三层地牢，击败最终的哥布林酋长。

- 每层由多个房间组成，清空房间内的敌人后即可前进。
- 角色可以选择 3 种职业，各有独特的技能和被动。
- 地牢中可以找到 11 种武器，从手枪到火箭筒、激光枪、雷电法杖、猎弓等。
- 每层有不同的主题（森林、冰原、熔岩），背景音乐也随之变化。

### 职业

| 职业 | 特点 | 技能 |
| --- | --- | --- |
| 骑士 | 血厚、护甲高，初始携带手枪 | **双持**：6 秒内同时使用两把武器，期间每击杀一个敌人延长 1 秒 |
| 游侠 | 移速最快，初始携带猎弓和手枪 | **翻滚**：翻滚闪避并无敌，之后 1.5 秒攻击必定暴击 |
| 法师 | 能量最多，所有伤害 +35% | **雷霆新星**：闪电秒杀周围普通怪物，重创精英与首领，并击碎附近子弹 |

### 武器

手枪、新手法杖、冲锋枪、霰弹枪、加特林、寒冰法杖、激光枪、火箭筒、雷电法杖、骑士大剑、猎弓。

### 敌人

哥布林枪手、哥布林祭司、狂暴野猪、史莱姆、蝙蝠，以及最终首领 **哥布林酋长**。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| 鼠标左键 | 射击（长按连发；猎弓需要蓄力） |
| 空格 / 鼠标右键 | 职业技能 |
| `Q` / 鼠标滚轮 | 切换武器 |
| `E` | 拾取武器 / 开宝箱 / 进入传送门 |
| `F` | 开关自动瞄准 |
| `M` | 静音 |
| `Esc` / `P` | 暂停 |

## 运行方式

项目是纯静态网页，任选一种方式即可。

**方式一：用本地静态服务器（推荐）**

```bash
cd soul-knight
python3 -m http.server 8765
```

然后在浏览器中打开 http://localhost:8765/

**方式二：直接打开**

也可以直接双击 `index.html` 在浏览器中打开，但推荐使用方式一，以避免浏览器对本地文件的限制。

## 项目结构

```
soul-knight/
├── index.html        游戏入口页面
├── debug.html        精灵图预览页（开发调试用）
├── js/
│   ├── util.js       工具函数与输入处理
│   ├── game.js       主循环、状态机、渲染管线、关卡流程
│   ├── level.js      关卡与房间生成
│   ├── entities.js   玩家、敌人、职业、首领等实体
│   ├── weapons.js    武器定义与射击逻辑
│   ├── tiles.js      地面与墙体瓦片，三套主题
│   ├── sprites.js    像素美术（由字符画程序化生成）
│   ├── fx.js         粒子、屏幕震动等特效
│   ├── hud.js        血条、能量条、武器栏等界面
│   └── audio.js      程序化合成的音效与背景音乐
└── .claude/          Claude Code 的开发辅助配置
```

美术资源全部由代码生成（`sprites.js` 中的字符画和 `tiles.js` 中的瓦片生成），音效和音乐由 Web Audio API 合成，仓库中没有图片或音频文件。

## 技术细节

- 渲染：Canvas 2D，像素风格通过关闭平滑和按整数倍缩放实现。
- 音频：Web Audio API 实时合成，每个主题有独立的和弦与旋律。
- 无依赖：没有 npm、没有打包工具，直接用 `<script>` 按顺序加载。
